# AI Software Factory v1.2

Vercel-ready Next.js workspace. The project root intentionally contains `app/` and `package.json` so it can be imported directly into Vercel.

## Deploy
1. Upload the contents of this folder to the root of a GitHub repository.
2. Import the repository into Vercel.
3. Framework preset: Next.js (auto-detected).
4. Build command: `npm run build`.
5. No Root Directory change is required.

## Local
npm install
npm run dev

## Security
The provider key fields in this MVP are browser-local UI state only. For production, use server-side encrypted storage and never commit real API keys.
